# 🎨 Meu Paint — Java Swing (NetBeans / Ant)

Um aplicativo de pintura digital desktop desenvolvido em Java com interface Swing e gerenciador de compilação Ant. O projeto permite a criação e renderização de diversas formas geométricas e suporte a desenho livre estilo pincel/caneta.

---

## 🛠️ Funcionalidades

- **Desenho Livre (Caneta):** Traçado contínuo e fluido com suporte a múltiplos pontos.
- **Formas Geométricas Básicas:**
  - 📏 Linha
  - ⬛ Retângulo
  - ⚪ Elipse
  - 🔷 Polígono regular (com definição dinâmica da quantidade de lados via diálogo)
- **Seleção de Cores:**
  - Seletor dedicado para **Cor do Contorno** (`JColorChooser`).
  - Seletor dedicado para **Cor de Preenchimento** (`JColorChooser`).
- **Arquitetura Orientada a Objetos:** Renderização modular e polimórfica de formas.

---

## 💻 Tecnologias Utilizadas

- **Linguagem:** Java
- **GUI Framework:** Java Swing
- **Build System:** Apache Ant
- **IDE Utilizada:** NetBeans
