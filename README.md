# 🎨 Meu Paint — Java Swing

> Interface gráfica de pintura digital desenvolvido em Java com interface Swing.

---

## 🎯 Principal Objetivo

Entender o funcionamento da pilha, primeira estrutura de dado linear estudada na disciplina, que é responsável pelo gerenciamento de dados no formato LIFO (Last In, First Out).

---

## 🛠️ Funcionalidades

- **Formas Geométricas Básicas:**
  - 📏 Linha
  - ⬛ Retângulo
  - ⚪ Elipse
  - 🔷 Polígono regular (com definição dinâmica da quantidade de lados via diálogo)
- **Texto:** É possível adicionar um texto através do InputDialog do JOptionPane.
- **Desenho Livre (Caneta):** Traçado contínuo e fluido.
- **Borracha:** Traçado contínuo que apaga os desenhos.
- **Preencher:** Quando selecionado, as formas tem seu interior pintado, caso contrário ficam transparentes.
- **Limpar Tela:** Aparece um ConfirmDialog do JOptionPane que ao ser confirmado apaga todos os desenhos da tela.
- **Pilha de Memória:** É possível desfazer (undo) e refazer (redo) os desenhos através das setinhas ou dos atalhos do teclado (Ctrl + Z / Ctrl + Y).
- **Seleção de Cores:**
  - Seletor dedicado para **Cor do Contorno** (`JColorChooser`).
  - Seletor dedicado para **Cor de Preenchimento** (`JColorChooser`).
- **Controle de espessura:** Através do Slider no canto esquerdo do painel, é possível escolher a espessura do desenho a ser realizado.

---

## 💻 Tecnologias Utilizadas

- **Linguagem:** Java
- **GUI Framework:** Java Swing
- **IDE Utilizada:** NetBeans
